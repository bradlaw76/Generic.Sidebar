Installation and administration

Set up Generic Sidebar safely

Use this guide to deploy the web resources, configure the table-driven side pane, connect optional Copilot agents, and validate the result in a model-driven app.

Design: the sidebar reads active configuration from Dataverse at runtime. Configuration changes normally do not require redeploying web resources.

Prerequisites

  • System Administrator or System Customizer access in the target Dataverse environment.
  • Access to the unmanaged Generic Sidebar solution and the model-driven app form to be wired.
  • A security role that can read sidebar_genericsidebar and active sidebar_genericsidebaragent rows.
  • For SSO: Copilot Studio, Entra app-registration, and tenant-admin access.

1. Deploy web resources

  1. Open the target environment and select the Generic Sidebar unmanaged solution.
  2. Upload or update the sidebar HTML and JavaScript web resources from the approved source repository.
  3. Publish customizations. Use a full publish only when a targeted publish is blocked by a concurrent customization operation.
  4. Hard refresh the model-driven app with Ctrl+Shift+R before testing.
Do not rename a web resource without updating every form event, embed configuration, Entra redirect URI, and deployment reference that uses it.

2. Configure Dataverse

  1. Create or select a row in sidebar_genericsidebar.
  2. Set exactly one intended row to sidebar_default = Yes. The runtime selects the most recently modified default as a safeguard; fix duplicate defaults rather than relying on that behavior.
  3. Set panel titles, instructions, and embed values. Use webresource:resource_name, a permitted URL, an iframe snippet, or raw HTML as appropriate.
  4. Set sidebar_agentmenutab only when the linked-agent picker should replace a configured tab.
FieldPurpose
sidebar_defaultIdentifies the active sidebar configuration.
sidebar_title1 through sidebar_title4Tab labels.
sidebar_embedcode variantsContent source for each tab.
sidebar_instructions variantsOptional instruction band above a tab.

3. Wire the model-driven app

  1. Add sidebar_sidebar.js as a form library.
  2. Add the approved sidebar entry function to Form OnLoad or the relevant ribbon command, and pass the execution context if the configured function requires it.
  3. Save and publish the form.
  4. Open a record in the app and confirm the pane opens with the intended default configuration.

4. Configure linked agents

  1. Create child rows in sidebar_genericsidebaragent and link each to its parent sidebar configuration.
  2. Set sidebar_isactive = Yes and leave the row in active Dataverse state.
  3. Set the parent menu-tab option to place the linked-agent picker in the intended tab.
  4. Verify inactive or deactivated child rows do not appear in the picker.

5. Enable Copilot SSO (optional)

  1. Deploy the SSO resources: sidebar_sso_bootstrap.js, sidebar_sso_setup.js, sidebar_sso_canvas.html, and sidebar_sso_config_validator.html.
  2. Register the canvas web-resource URL as a SPA redirect URI in Entra ID.
  3. Populate the approved public configuration values: client ID, tenant ID, scope, token endpoint, redirect URI, and optional additional scopes.
  4. Run the SSO validator, then test only inside the hosted model-driven application.
Never store a client secret in Dataverse configuration read by browser web resources. The supported browser flow uses PKCE.

6. Validate before release

  • One correct default configuration is active.
  • All configured tabs load, and expected instructions render.
  • External content is permitted to render in an iframe.
  • Active linked agents appear; inactive agents do not.
  • Non-SSO configuration works before SSO is enabled.
  • SSO popup and silent sign-in paths work in hosted Dynamics without exposing tokens in logs.

Operations and rollback

Record the Git commit, environment, web-resource names, and validation evidence for every deployment. If a regression occurs, restore the approved Git checkpoint, import the known-good resources, publish, and hard refresh.

git restore --source admin-review-baseline-2026-08-05 -- .

Troubleshooting

SymptomAction
Pane is blankConfirm the default row, form event, resource name, and publish state.
Agent picker is emptyConfirm parent lookup, sidebar_isactive, and active state for each child row.
SSO fails to startValidate the exact redirect URI, SPA platform type, scope, and Copilot token endpoint.
Old UI appearsPublish then hard refresh; verify the web-resource content stored in Dataverse before assuming browser cache.
