Step 6A Preview: Agent Catalog Child Table

Visual preview of the Dataverse schema for multi-agent Generic Sidebar support. Parent table remains sidebar_genericsidebar. Child table stores one row per agent.

Recommended Table Definition

SettingValue
Display nameGeneric Sidebar Agent
Plural display nameGeneric Sidebar Agents
Logical namesidebar_genericsidebaragent
Primary columnsidebar_name
Parent relationshipMany agent rows to one sidebar_genericsidebar row

Relationship Behavior

  • Create a standard Dataverse lookup from Generic Sidebar Agent to Generic Sidebar.
  • Keep shared SSO defaults on the parent sidebar_genericsidebar record.
  • Use child rows for agent-specific metadata and routing values.
  • Do not move sidebar_embedcode fields into the child table for v1.
Parent: sidebar_genericsidebar Child: sidebar_genericsidebaragent One-to-many
